# Data availability

The source workbook is not included because the rural survey records contain restricted research data, village names, and geographic coordinates.

This repository publishes only:

- the data architecture;
- representative Excel matching formulas;
- aggregate row and year coverage;
- the quality-control workflow; and
- a printable project summary.

The public NOAA station reference used by the broader project is available at:

https://www.ncei.noaa.gov/pub/data/ghcn/daily/ghcnd-stations.txt

No confidential or row-level village information is redistributed here.
